# 演示操作指南（给演示人员）

本指南写给不熟悉技术的演示人员：照着下面的顺序点击即可完成一场完整演示。
整场演示约 8~10 分钟，核心环节是「商品资料文档问答」。

---

## 一、开始前的准备（请技术人员执行一次）

1. 打开命令行，进入项目目录，例如：

   ```bash
   cd D:\aizhibo\ai-live-ops-assistant
   ```

2. 启动系统（窗口保持打开，不要关闭）：

   ```bash
   .venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

   看到 `Application startup complete` 即启动成功。

   > 演示入口说明：默认 `http://127.0.0.1:8000` 为 Vue3 前端（正式演示入口）；旧版单页前端保留为回退入口 `http://127.0.0.1:8000/legacy`（功能一致，备用）。若 Vue3 页面未正常显示，请让技术人员在 `frontend/` 目录执行一次 `npm ci && npm run build` 后重启。

3. 如果这是第一次演示（数据库是空的），请先按下面「附录 A」准备演示数据，约 2 分钟。
4. 若需演示「语义检索 + 资料完整度」环节，请让技术人员确认 `.env` 已配置 Embedding（OpenAI-compatible API，例如 `text-embedding-v4`；配置方法见 README「Embedding / 向量检索配置」，Key 使用占位符填写，勿写真实 Key）。未配置时，商品问答自动使用基础资料检索，其余环节不受影响。

## 二、登录

1. 浏览器打开：`http://127.0.0.1:8000`
2. 输入账号 `admin`、密码 `123456`，点登录。
3. 登录后默认进入「运营工作台」页面。

> 如果提示登录失败，请让技术人员确认 `.env` 中 `APP_ACCESS_PASSWORD` 是否为 `123456`；
> 若为留空（免登录模式），随便输入任意密码即可进入。

## 三、演示步骤（照着点）

### 第 1 步：运营工作台（默认页）

- 指着页面上的统计卡片介绍：商品资料、直播中商品、已生成话术、评论回复、直播复盘、商品资料文档。
- 强调：这些数字全部来自系统里的真实操作记录，不是写死的。
- 指着顶部「🎯 开播准备」横幅与「去完善商品资料」按钮：这是 V2 的开播准备入口，一键进入商品资料页。

### 第 2 步：商品资料与商品资料文档

1. 左侧菜单点「商品资料」。
2. 点已有商品「水润修护精华液」（若列表为空，先按附录 A 创建）。
3. 选中商品后，先看顶部「✅ 资料完整度」卡片：
   - 展示**百分比、缺失项、下一步建议**；上传资料前后各看一次，完整度明显上升——体现"缺什么补什么"。
4. 向下滚动到「📚 商品资料文档」卡片，依次演示：
   - **看列表**：指出列表中的 `faq.txt`（1 个片段）。
   - **查看片段**：点「查看片段」→ 下方展开该文件的完整内容（敏感肌 / 适用人群 / 售后三组问答）。
   - **重建资料索引**：点「重建该文件索引」→ 已配置 Embedding 时提示"重新整理完成，共 N 个片段"（真实重建语义索引）；
     未配置时提示"资料索引功能未启用"。
     说明：两种提示都正常——未配置时商品问答会自动使用基础资料检索，不影响演示。
   - **上传资料（可选加分项）**：点「上传资料」选一个 PDF / TXT / MD / CSV 文件 →
     弹窗显示"上传成功！共 N 个片段"，列表中立即出现该文件。
   - **删除（可选）**：点「删除」可移除资料，演示前请先确认，避免删掉要用的资料。

### 第 3 步：商品资料问答（核心环节）

在提问输入框依次输入以下问题并点「提问」（每次等待约 5~10 秒属正常，AI 在真实计算）：

| 输入的问题 | 期望回答要点（来自已上传资料） |
|---|---|
| `敏感肌能不能用？` | 不含酒精、香精和色素，经敏感肌斑贴测试，首次使用建议耳后测试 |
| `这款商品适合什么人群？` | 18-45 岁、皮肤干燥缺水或需要维稳修护，干性中性更佳 |
| `售后规则是什么？` | 7 天无理由退换（未拆封）、30 天质量问题、过敏凭证明全额退款 |

- 每次回答下方都会显示「参考片段：faq.txt#1」——强调回答来自已上传资料，不是 AI 瞎编。

**V2 语义检索环节（已配置 Embedding 时演示，约 1 分钟）**：

1. 上传一份新资料，内容只写一句：`换季脆弱肌适用，屏障不稳时可作为日常护理。`
2. 提问「敏感肌能不能用？」→ 参考片段应召回这份新资料。
   - 讲解点：问题和资料几乎没有相同字词，能命中说明系统在按"语义"理解，而不是简单关键词匹配。

### 第 4 步：直播话术

1. 仍在商品详情页，点「🎙 生成直播话术」（等待 5~10 秒）。
2. 展示生成的七模块主播话术：开场引入 → 商品卖点讲解 → 用户痛点刺激 → 互动提问 → 优惠逼单 → 异议回应 → 结尾转化。
3. 话术严格基于商品资料，不编造功效与承诺。

### 第 5 步：直播复盘

1. 商品详情页向下滚动到「📋 直播复盘」卡片，点「生成复盘」（等待 5~10 秒）。
2. 指出复盘的四个固定模块标题：
   - **用户关注点**
   - **常见异议**
   - **高频问题**
   - **下场直播优化建议**
3. 可顺带指出开头的诚实声明（如"当前评论样本较少"）——系统不会编造直播场次、销量、GMV 等未统计指标。

### 第 6 步：评论助手

1. 左侧菜单点「评论助手」。
2. 商品下拉框选择「水润修护精华液」。
3. 点快捷按钮「多少钱？」或手动输入一条评论 → 点「🎤 生成回复」。
4. 展示主播口吻回复（结合价格、优惠信息）。
5. 可再点「敏感肌能用吗？」演示不同评论生成不同回复。

### 第 7 步：回到看板看数据变化（收尾）

1. 左侧菜单点「运营工作台」。
2. 对比开场时的数字：话术、评论回复、复盘计数各 +1——演示"数据闭环"。
3. 高频评论区域会出现刚才提问过的评论（如"多少钱？"）。

### 第 8 步（可选）：直播素材库 vs 商品资料文档

1. 左侧菜单点「直播素材库」：上传品牌介绍、通用售后政策、活动规则等通用资料 → 在「资料问答」提问。
2. 讲解边界：
   - **商品资料文档**绑定具体商品，只服务该商品的问答、开播话术、评论助手、复盘。
   - **直播素材库**是通用资料池（品牌、规则、合规话术），独立于商品。
   - 两者各自检索、互不混检——商品问答只查当前商品的资料文档。

### 第 9 步（V3）：本地快答与问题洞察（约 2 分钟）

1. 回到「商品资料」页，选中商品「水润修护精华液」。
2. **本地快答**：在「商品资料文档」的提问框依次提问，观察返回速度（无需等待 AI）：
   - `多少钱` → 立即返回价格（「以直播间实际展示为准」）
   - `还有库存吗` → 立即返回库存（「以实际下单页面为准」）
   - 讲解点：价格、库存这类低风险问题由系统**本地规则直接回答**，不调 AI，更快更稳。
3. **高风险不快答**：提问 `孕妇能不能用` → 不会本地直答，而是走商品资料检索（资料未覆盖时提示补充）。
   - 讲解点：涉及风险边界的问题系统不会拍脑袋，只按资料回答，缺资料就提示补充。
4. **问题洞察**：向上滚动到「❓ 问题洞察」卡片，指出：
   - 🔥 高频问题：刚才的问题按次数排序出现
   - 📊 分类统计：价格 / 库存 / 风险边界等分类计数
   - ⚠️ 未覆盖问题：未命中资料的问题在此提示「建议补充资料」
   - 🕒 最近问题：按时间倒序，标注已回答 / 未覆盖
5. **评论助手也沉淀**：去「评论助手」给该商品生成一条回复 → 回到商品资料页点洞察「刷新」→ 这条评论也进入分类统计与最近问题。
   - 讲解点：系统在沉淀"观众/运营最常问什么"，后续复盘和话术都有据可依。

### 第 10 步（V4）：运营建议与常问应答话术（约 2 分钟）

前置：第 9 步已积累若干问题（"多少钱"问 2 次以上 + 一次"孕妇能不能用"）。

1. 商品资料页 → 打开「问题洞察」Tab，指着顶部「💡 运营建议」卡片：
   - 摘要三格：建议总数 / 高优先级 / 资料状态（建议补资料 / 暂不需要补资料）
   - 列表逐条讲解：
     - **资料补齐**：建议补充风险边界资料（来源问题：孕妇能不能用）
     - **FAQ 建议**：高频问题"多少钱"建议沉淀为 FAQ
     - **话术强化**：价格类问题建议直播间主动讲清
     - **风险提醒**：开播前确认风险边界，不做医疗或功效承诺
   - 讲解点：**系统不是只展示问题，而是告诉运营该补什么资料、该讲什么。**
2. 点击「🎙 生成直播话术」（自动跳到「开播话术」Tab）：
   - 话术中新增「八、直播间常问应答」模块——主动回应"多少钱"等高频问题；
   - 未覆盖问题（如孕妇能不能用）以"资料暂未明确，建议补充后再承诺"谨慎表达，不编造。
3. 收尾讲解：V4 把"用户常问什么"变成了"该补什么资料、该讲什么话"，建议全部来自真实问题记录，不是拍脑袋。

## 四、常见情况说明

| 情况 | 说明 | 演示时怎么讲 |
|---|---|---|
| 提问/生成等待 5~10 秒 | AI 在真实调用大模型计算 | "AI 正在基于资料生成回答，稍等" |
| 提问后立即返回、无等待 | 价格/库存等低风险问题由本地规则直接回答 | "系统对常见问题做了本地直答，更快更稳" |
| 提示"AI 服务暂时不可用，已返回本地兜底" | 断网或 API Key 失效，系统自动降级 | "系统有本地兜底能力，断网也能演示不中断" |
| 「重建该文件索引」提示"资料索引功能未启用" | 未配置 Embedding 时返回的诚实提示 | "商品问答会自动使用基础资料检索，不影响演示" |
| 复盘提示"当前评论样本较少" | 评论记录少于 3 条 | "系统不会编造数据，样本少会如实说明" |

## 附录 A：首次演示准备数据（数据库为空时）

1. 登录后进入「商品资料」，点「新增商品」，填写并保存：
   - 商品名称：`水润修护精华液`
   - 价格：`129`；库存：`500`
   - 核心卖点：`三重玻尿酸深层补水，添加神经酰胺修护屏障`
   - 适用人群：`18-45岁干性、中性及敏感肌人群`
   - 用户痛点：`皮肤干燥紧绷、换季泛红、上妆卡粉`
   - 优惠信息：`直播间下单买二送一`
   - 直播状态：`直播中`
2. 点开该商品，在「📚 商品资料文档」卡片点「上传资料」，选择任意 TXT 文件（可让技术人员按附录 B 准备），或现场新建一个 TXT 粘贴以下内容后上传：

   ```text
   商品FAQ
   Q：敏感肌能不能用？
   A：可以。本精华配方不含酒精、香精与色素，经敏感肌斑贴测试，敏感肌人群可放心使用；首次使用建议先在耳后测试。
   Q：这款商品适合什么人群？
   A：适合18-45岁、皮肤干燥缺水或需要维稳修护的人群，干性与中性皮肤效果更佳。
   Q：售后规则是什么？
   A：支持7天无理由退换（未拆封）；拆封后如有质量问题30天内包退换；使用后过敏可凭医院过敏证明申请全额退款。
   ```

3. 准备完成，返回「三、演示步骤」从第 1 步开始。

## 附录 B：演示数据文件说明

- 推荐预置 1 个商品 + 1 个 FAQ 文档即可完成全部演示环节。
- 上传支持 PDF / TXT / MD / CSV 四种格式，单文件不超过 10MB（可在 `.env` 调整）。
