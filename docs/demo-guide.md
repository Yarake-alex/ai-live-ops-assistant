# 演示操作指南（给演示人员）

本指南写给不熟悉技术的演示人员：照着下面的顺序点击即可完成一场完整演示。
整场演示约 8~10 分钟，核心环节是「商品知识库 RAG 问答」。

---

## 一、开始前的准备（请技术人员执行一次）

1. 打开命令行，进入项目目录，例如：

   ```bash
   cd D:\aizhibo\ai-live-ops-assistant
   ```

2. 启动系统（窗口保持打开，不要关闭）：

   ```bash
   .venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

   看到 `Application startup complete` 即启动成功。

3. 如果这是第一次演示（数据库是空的），请先按下面「附录 A」准备演示数据，约 2 分钟。

---

## 二、登录

1. 浏览器打开：`http://127.0.0.1:8000`
2. 输入账号 `admin`、密码 `123456`，点登录。
3. 登录后默认进入「运营看板」页面。

> 如果提示登录失败，请让技术人员确认 `.env` 中 `APP_ACCESS_PASSWORD` 是否为 `123456`；
> 若为留空（免登录模式），随便输入任意密码即可进入。

---

## 三、演示步骤（照着点）

### 第 1 步：运营看板（默认页）

- 指着页面上的统计卡片介绍：商品数、直播中商品、话术数、评论回复数、复盘数、知识库文档数。
- 强调：这些数字全部来自系统里的真实操作记录，不是写死的。

### 第 2 步：商品管理与商品知识库

1. 左侧菜单点「商品管理」。
2. 点已有商品「水润修护精华液」（若列表为空，先按附录 A 创建）。
3. 向下滚动到「📚 商品知识库」卡片，依次演示：
   - **看列表**：指出列表中的 `faq.txt`（1 个片段）。
   - **查看片段**：点「查看片段」→ 下方展开该文件的完整内容（敏感肌 / 适用人群 / 售后三组问答）。
   - **重建该文件索引**：点一下 → 弹窗提示"商品知识库使用本地关键词检索，无需重建索引"。
     说明：这是正常提示，不是报错——当前版本商品知识库用关键词检索，索引即时生成，无需重建。
   - **上传资料（可选加分项）**：点「上传资料」选一个 PDF / TXT / MD / CSV 文件 →
     弹窗显示"上传成功！共 N 个片段"，列表中立即出现该文件。
   - **删除（可选）**：点「删除」可移除资料，演示前请先确认，避免删掉要用的资料。

### 第 3 步：商品资料问答（核心环节）

在提问输入框依次输入以下问题并点「提问」（每次等待约 5~10 秒属正常，AI 在真实计算）：

| 输入的问题 | 期望回答要点（来自已上传资料） |
|---|---|
| `敏感肌能不能用？` | 不含酒精、香精和色素，经敏感肌斑贴测试，首次使用建议耳后测试 |
| `这款商品适合什么人群？` | 18-45 岁、皮肤干燥缺水或需要维稳修护，干性中性更佳 |
| `售后规则是什么？` | 7 天无理由退换（未拆封）、30 天质量问题、过敏凭证明全额退款 |

- 每次回答下方都会显示「参考片段：faq.txt#1」——强调回答来自已上传资料，不是 AI 瞎编。

### 第 4 步：直播话术

1. 仍在商品详情页，点「🎙 生成直播话术」（等待 5~10 秒）。
2. 展示生成的七模块主播话术：开场引入 → 商品卖点讲解 → 用户痛点刺激 → 互动提问 → 优惠逼单 → 异议回应 → 结尾转化。
3. 话术严格基于商品资料，不编造功效与承诺。

### 第 5 步：直播复盘

1. 商品详情页向下滚动到「📋 直播复盘」卡片，点「生成复盘」（等待 5~10 秒）。
2. 指出复盘的四个固定模块标题：
   - **用户关注点**
   - **常见异议**
   - **高频问题**
   - **下场直播优化建议**
3. 可顺带指出开头的诚实声明（如"当前评论样本较少"）——系统不会编造直播场次、销量、GMV 等未统计指标。

### 第 6 步：评论回复

1. 左侧菜单点「评论回复」。
2. 商品下拉框选择「水润修护精华液」。
3. 点快捷按钮「多少钱？」或手动输入一条评论 → 点「🎤 生成回复」。
4. 展示主播口吻回复（结合价格、优惠信息）。
5. 可再点「敏感肌能用吗？」演示不同评论生成不同回复。

### 第 7 步：回到看板看数据变化（收尾）

1. 左侧菜单点「运营看板」。
2. 对比开场时的数字：话术、评论回复、复盘计数各 +1——演示"数据闭环"。
3. 高频评论区域会出现刚才提问过的评论（如"多少钱？"）。

---

## 四、常见情况说明

| 情况 | 说明 | 演示时怎么讲 |
|---|---|---|
| 提问/生成等待 5~10 秒 | AI 在真实调用大模型计算 | "AI 正在基于资料生成回答，稍等" |
| 提示"AI 服务暂时不可用，已返回本地兜底" | 断网或 API Key 失效，系统自动降级 | "系统有本地兜底能力，断网也能演示不中断" |
| 「重建该文件索引」提示无需重建 | 商品知识库用关键词检索（当前设计） | "这是诚实提示：当前检索方式是即时的，不需要索引" |
| 复盘提示"当前评论样本较少" | 评论记录少于 3 条 | "系统不会编造数据，样本少会如实说明" |

## 附录 A：首次演示准备数据（数据库为空时）

1. 登录后进入「商品管理」，点「新增商品」，填写并保存：
   - 商品名称：`水润修护精华液`
   - 价格：`129`；库存：`500`
   - 核心卖点：`三重玻尿酸深层补水，添加神经酰胺修护屏障`
   - 适用人群：`18-45岁干性、中性及敏感肌人群`
   - 用户痛点：`皮肤干燥紧绷、换季泛红、上妆卡粉`
   - 优惠信息：`直播间下单买二送一`
   - 直播状态：`直播中`
2. 点开该商品，在「📚 商品知识库」卡片点「上传资料」，选择任意 TXT 文件（可让技术人员按附录 B 准备），或现场新建一个 TXT 粘贴以下内容后上传：

   ```text
   商品FAQ
   Q：敏感肌能不能用？
   A：可以。本精华配方不含酒精、香精与色素，经敏感肌斑贴测试，敏感肌人群可放心使用；首次使用建议先在耳后测试。
   Q：这款商品适合什么人群？
   A：适合18-45岁、皮肤干燥缺水或需要维稳修护的人群，干性与中性皮肤效果更佳。
   Q：售后规则是什么？
   A：支持7天无理由退换（未拆封）；拆封后如有质量问题30天内包退换；使用后过敏可凭医院过敏证明申请全额退款。
   ```

3. 准备完成，返回「三、演示步骤」从第 1 步开始。

## 附录 B：演示数据文件说明

- 推荐预置 1 个商品 + 1 个 FAQ 文档即可完成全部演示环节。
- 上传支持 PDF / TXT / MD / CSV 四种格式，单文件不超过 10MB（可在 `.env` 调整）。
- 演示数据保存在本地数据库文件中，不会随代码提交；换一台电脑演示需要重新准备。
